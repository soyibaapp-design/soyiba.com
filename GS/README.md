# GS

Cada subcarpeta representa un modulo/pantalla de Google Apps Script.

- `Auth/Code.gs`: autenticacion por correo y contrasena.
- `Inicio/Code.gs`: resumen inicial de la app y entidad `Publicaciones` con hojas `Publicaciones` y `Guardados`.

Cuando se cree una nueva pantalla, agregar `GS/NOMBRE/Code.gs` y desplegarla como servicio independiente si la pantalla requiere endpoint propio.
